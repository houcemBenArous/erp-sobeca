Plan de Migration en 5 Phases

Phase 1 — Analyse & Préparation

Durée : 2-3 semaines
Tâches Principales
  • Audit complet de la base SQL Server (246 tables)
  • Identification des anomalies et doublons
  • Nettoyage préalable :
    • 5 articles orphelins dans mouvement_stock
    • 4 montants non numériques dans commande_client.total_ht
    • Casse incohérente dans type_operation
  • Extraction des données métier critiques
  • Définition des règles de transformation
Points d'Attention
Anomalies connues à traiter :
  • 5 articles orphelins (mouvements sans article)
  • 4 montants HT non numériques
  • Casse incohérente : "entrée" vs "Entrée"
  • Tables gmao appartiennent à CONSOMED (ignorer)
TopSolid PDM vierge
0 plan CAO → aucun plan EDV migrable

Phase 2 — Création Base PostgreSQL

Durée : 1 semaine
Tâches Principales
  • Création schéma PostgreSQL complet (108 tables)
  • Import des référentiels de base :
    • article (Articles + Matières premières)
    • client (Clients actifs)
    • fournisseur (Fournisseurs agréés)
    • machine (Parc machines)
    • operateur (Personnel production)
  • Validation des contraintes d'intégrité
  • Indexation des clés primaires/étrangères

Phase 3 — Migration Transactionnelle

Durée : 2 semaines
Données Transactionnelles
  • 18 393 Commandes Clients (2020-2024)
    • Historique complet avec dates, montants, statuts
    • Relation 1:1 avec Ordres de Fabrication (NCD = OF)
  • Ordres de Fabrication (OF)
    • Numérotation 8 chiffres : AAAANNNN
    • Traçabilité complète des exécutions
  • Mouvements de Stock
    • 4 dépôts : M1, M02, ML, DPF
    • Types : Entrée, Sortie, Transfert, Inventaire
  • Bons de Commande Fournisseurs
  • Fiches Techniques Produits
Filtres & Transformations
Filtrage optionnel par société :
3 tables contiennent une colonne société :
  • commande_client
  • fiche_technique
  • mouvement_stock
Filtrer sur société = 'SOBECA' si données mixtes
Transformation des statuts :
4 statuts SQL Server → 7 statuts ERP
Annulé | En cours | Terminé | En attente → mapping détaillé dans ERP-12

Phase 4 — Validation Métier

Durée : 2-3 semaines
Tests & Validations
  • Environnement miroir complet
  • Validation des 22 KPI
    • Recalcul sur données historiques
    • Comparaison avec Excel FOR-MQA-02
  • Recette utilisateur par processus
    • RMQ : Audits, FAA, 8D, NC
    • Commercial : Offres, Commandes, Réclamations
    • Production : OF, Fiches suiveuses, Contrôle
    • Achats : BC fournisseurs, Réceptions, Stock
  • Tests de charge (connexions simultanées)
  • Corrections et ajustements
Critères de Validation
100% des commandes 2024 accessibles
Stock actuel cohérent (4 dépôts)
OF en cours visibles et modifiables
Traçabilité lot → pièce fonctionnelle
22 KPI calculables et cohérents
Aucune erreur FK (intégrité référentielle)
Temps de réponse < 2s par écran

Modules Créés *From Scratch* (Pas de Migration)

MNT - Maintenance

Aucune table SQL Server

Gestion historique sur Excel uniquement. Import initial depuis FOR-MNT-23 (machines) et FOR-MNT-24 (instruments).

GRH - Ressources Humaines

5 tables GRH vides

Module démarre vide. Import effectifs au go-live via FOR-GRH-05 (25 personnes).

MQA - Management Qualité

Module inexistant dans ancienne base

Module transversal créé de zéro. Démarrage avec audits et FAA 2026 uniquement.
